# 🍔 Задание 3. Автотесты для UI

Необходимо протестировать веб-приложение **Stellar Burgers**.

---

### 🛠️ Что нужно сделать:
* **Page Object**: Опиши элементы, которые будешь использовать в тестах, с помощью паттерна Page Object.
* **Браузеры**: Протестируй функциональность в **Google Chrome** и **Яндекс Браузере**.
* **Отчеты**: Подключи **Allure-отчёт** для визуализации результатов.
